# 崩铁：欢愉令使星，诸天攒愿伐贪饕

诸天同人长篇。开拓者星成为欢愉令使，与阿哈、花火、桑博组成四人小队，穿行不同世界收集由本心诞生的欢愉愿力，为抵抗正在复苏的贪饕做准备。

四人一路找乐子，也会在力所能及的范围内弥补原作遗憾。能救的人认真救，已经发生的伤害不强行抹除；改变剧情之后，继续书写新的责任、创伤与因果。

## 核心人物

- **星**：欢愉令使，松弛嘴欠，穷酸搞怪，关键时刻可靠。
- **阿哈**：愿力保管者和第四名队员，以分身、面具或声音随队，负责开门、托底与临时加节目。
- **花火**：假面愚者，擅长变装、舞台、假身份和把坏结局演成意外结局。
- **桑博**：假面愚者兼情报商，贪财惜命、嘴贫圆滑，负责渠道、补给和撤退路线。

四人无条件信任彼此。可以恶作剧、偷面具、藏私房钱和临时改戏，但不会背叛、挪用愿力或隐瞒致命风险。

## 写作原则

1. 欢愉是选择权，不是强制幸福。
2. 不篡改记忆，不洗脑，不强行制造感情，不复活已经死亡的人。
3. 原作名场面可以改变，不能为了保留悲剧让四人故意见死不救。
4. 能弥补的遗憾尽量弥补，改变后必须承担新的世界线因果。
5. 各世界沿用原作反派和社会矛盾，不设置贪饕残响或幕后污染。
6. 整体以银魂式轻松冒险为主，严肃情节克制，不连续堆叠苦难。
7. 阿哈收集愿力只为维持诸天通道和抵抗贪饕。
